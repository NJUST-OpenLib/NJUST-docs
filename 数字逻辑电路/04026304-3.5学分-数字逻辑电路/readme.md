**复习建议**：想要速通的同学，建议跳过第二章，因为本章知识点较为抽象而且在期末考试中考察占比不高（比如说在2026年的期末考中只有一道填空题），但是如果你要考研建议到时候要好好复习这一章。
**推荐复习顺序**：第一章->第三四五六章->第七九章->第八章->（第二章）。
## 考试题型说明
1. 第一章是基础；
2. 第二七九章只会以客观题的形式考察；
3. 第八章必考察一道大题（一般是最后一题或倒数第二题，不过都是比较简单）
4. 其余大题出自第三四五六章
   - 可能是一道组合逻辑电路的分析、
   - 一道组合逻辑电路的设计（74138和数据选择器，全加器是重点）、
   - 一道触发器的分析（状态方程+驱动方程+输出方程、状态表+状态图、波形）、
   - 一道时序逻辑电路的分析
   - 一道时序逻辑电路的设计
