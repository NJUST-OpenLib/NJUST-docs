## 实验内容说明
1. 前面的小实验比较简单很快就能完成。
2. 在搭建含电容的电路请注意到电容的极性，电容的极性错误会导致电路无法正常工作，甚至可能会出现~~火光~~。
3. 在搭建含运算放大器的电路时，注意不要让运算放大器短路，否则会问到~~阵阵飘香~~。
4. 数字钟实验搭建较为复杂，建议大家先看电路图，了解功能结构，再动手搭建。
5. 一般先搭建数字钟的计时电路，再搭建数字钟的清零电路和校分电路，最后搭建数字钟的报时电路。
6. 有问题先对照电路图查看接线，如果自己排查不出错误，请在必要时向老师请教，**特别是计时电路无法正常工作时**。

## 实验成绩说明
同前面的学长相同，本人的指导老师也是丁淑艳老师。最后以`33/45`的排名得了`良+`，所以说有志在冲击高分的同学，数字钟要做得快而好。
当然老师也是会批改实验报告的，实验报告对最终成绩也有一定影响。
不过只要完整地完成实验要求的所有功能，且老师要求的内容都有那么肯定能拿`良(80分)`。
>不同老师要求做的实验内容可能不同，对实验报告的要求也不同。据我所知，孙理老师只要求数字钟需要写报告。
